# Tutorial de Séries Temporais

Um repositório educacional contendo um tutorial detalhado sobre análise, modelagem e previsão de séries temporais. 
O material foi desenvolvido com foco no rigor estatístico, cobrindo desde a fundamentação teórica até a aplicação prática dos principais modelos de previsão quantitativa.

## Conteúdo Abordado

* **Análise Exploratória:** Decomposição de séries, avaliação de componentes de tendência e sazonalidade.
* **Estacionariedade:** Testes de raiz unitária e processos de diferenciação.
* **Modelos de Suavização:** Médias móveis e métodos de Suavização Exponencial.
* **Metodologia Box-Jenkins:** Identificação, estimação, diagnóstico e previsão utilizando modelos ARIMA e SARIMA.
* **Validação de Modelos:** Análise criteriosa de resíduos, verificação de ruído branco e métricas de desempenho preditivo.

## Tecnologias e Ferramentas

* Linguagem R
* RMarkdown
* Pacotes principais: `forecast`, `ggplot2`
